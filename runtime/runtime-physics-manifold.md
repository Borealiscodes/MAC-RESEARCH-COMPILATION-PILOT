🌍 Manifold Runtime Overview

Manifold runtime physics models computation as movement across runtime patches
within an atlas. Each patch corresponds to an altitude-specific operational
region, and transitions between patches are governed by membrane constraints and
runtime operators.

• Patches → runtime regions  
• Charts → activation maps  
• Atlas → complete runtime coverage  
• Operators → membrane-bounded transitions  

🗺️ Runtime Patches

A runtime patch is a bounded operational region associated with a specific
altitude and membrane.

Patch Properties:
• altitude-tagged  
• membrane-tagged  
• locally reversible  
• contamination-safe  

Patch Example:
• Patch A2: Meaning-geometry runtime region  
• Patch A3: Formal runtime region  

🧭 Activation Charts

Activation charts define how runtime operators behave within a patch and how
they transition between patches.

Chart Requirements:
• deterministic  
• membrane-preserving  
• altitude-consistent  
• reversible unless provenance-bound  

Chart Structure:
• domain: patch region  
• codomain: adjacent patch  
• operator: transition function  

🗂️ Atlas Structure

The atlas is the complete set of runtime patches and activation charts.

Atlas Invariants:
• full coverage of runtime states  
• no gaps between patches  
• no overlapping membranes  
• reversible transitions across charts  

Atlas Diagram (ASCII-Safe):

Each ↔ is a membrane-constrained chart.
