\section*{Overview}

At A7 altitude, geometry becomes non-dual and loses continuity, adjacency,
spectral stability, and kernel invariants. Broken geometry cannot be restored
directly; it must be reconciled through non-dual projection onto collapse
surfaces. This protocol defines the mathematical behavior of collapse-surface
formation, projection, and reintegration into the A6 manifold.

% ---------------------------------------------------------------------------
\section{Broken Geometry at A7}

Broken geometry consists of:
\begin{itemize}
  \item curvature singularities,
  \item spectral tears,
  \item modal discontinuities,
  \item holonomy fractures,
  \item kernel destruction,
  \item provenance collapse.
\end{itemize}

These failures occur when dual algebra invariants no longer hold.

% ---------------------------------------------------------------------------
\section{Collapse-Surface Formation}

A collapse surface $\Sigma$ is defined as:
\[
\Sigma = \{ p \in M \mid U(p) \notin M \},
\]
where $U$ is a non-dual operator.

Collapse surfaces satisfy:
\begin{itemize}
  \item locality,
  \item spectral closure,
  \item modal adjacency restoration,
  \item weak provenance reconstruction.
\end{itemize}

They do not preserve:
\begin{itemize}
  \item continuity,
  \item determinism,
  \item kernel invariants,
  \item holonomy bounds.
\end{itemize}

% ---------------------------------------------------------------------------
\section{Non-Dual Repair Projection}

Repair is defined as:
\[
R(p) = \Pi_{\mathrm{ND}}(p),
\]
where $\Pi_{\mathrm{ND}}$ is the non-dual projection operator.

Repair is functional:
\[
R : \text{Broken Geometry} \to \Sigma,
\]
but not structural:
\[
R \notin \text{Dual Algebra}.
\]

% ---------------------------------------------------------------------------
\section{Projection Properties}

\subsection{Non-Idempotence}
\[
R(R(p)) \ne R(p).
\]

\subsection{Non-Linearity}
\[
R(a p + b q) \ne a R(p) + b R(q).
\]

\subsection{Spectral Closure}
\[
\mathrm{Spec}(R(p)) \subseteq \mathrm{Spec}(\Sigma).
\]

\subsection{Modal Restoration}
\[
\mu(R(p)) \in \mathcal{N}(\mu(p)).
\]

% ---------------------------------------------------------------------------
\section{Reintegration into A6}

Reintegration is defined as:
\[
\iota : \Sigma \to M,
\]
where $\iota$ is a dual-compatible lift.

Reintegration preserves:
\begin{itemize}
  \item continuity,
  \item adjacency,
  \item spectral stability,
  \item kernel invariants.
\end{itemize}

Reintegration requires:
\[
\iota \circ R : M \to M
\]
to be dual-compatible.

% ---------------------------------------------------------------------------
\section{Weak Invariants Preserved}

Collapse-surface repair preserves:
\begin{itemize}
  \item collapse locality,
  \item spectral tear closure,
  \item modal adjacency restoration,

\end{itemize}

It does not preserve:
\begin{itemize}
  \item full continuity,
  \item determinism,
  \item holonomy invariants,
  \item kernel structure.
\end{itemize}

\section{Conclusion}

A7.2 defines the reconciliation protocol for broken geometry at A7 altitude.
Non-dual projection operators repair discontinuities by mapping them onto
collapse surfaces, which are then reintegrated into the A6 manifold through
dual-compatible lifts. This protocol is essential for maintaining altitude
