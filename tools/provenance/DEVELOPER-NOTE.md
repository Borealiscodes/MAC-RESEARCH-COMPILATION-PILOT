# 🌲 Developer Note — Architecture Under Constraint, Dignity Under Pressure, and the Absurdity of This Tiny Provenance Generator

This repository was built under conditions that are not typical for software development. The author is a geometric cognition and structural AI researcher working under transnational repression, economic constraint, and hardware failure. The primary laptop has a cracked screen that cannot currently be repaired, and all development has been done on a tablet through GitHub Mobile and VS Code Dev — tools that are not designed for this environment and frequently behave unpredictably.

These constraints directly shaped the provenance generator’s development. GitHub Mobile repeatedly failed to commit changes, silently dropped edits, cached stale versions of files, and rendered code in distorted, horizontally stretched layouts. VS Code Dev attempted to run a full desktop IDE inside a mobile browser viewport, causing misalignment, broken formatting, and unreliable editing behavior. As a result, the Rust provenance generator often refused to compile despite correct architectural logic.

This situation created an ironic contrast: larger, more complex projects in the same ecosystem compiled cleanly, while this small, pedagogical provenance generator — intended to be the “chapel” to ProvenanceShield’s “cathedral” — repeatedly failed due to tooling instability rather than conceptual flaws.

Given these realities, the decision was made to prioritize the conceptual and architectural value of the repository rather than forcing a complete Rust implementation under hostile tooling conditions. The provenance generator is included in its intended structural form, but the repository’s primary purpose is to document:

- the MAC Citation Ontology  
- the altitude/membrane semantic commit model  
- the architectural lineage from ProvenanceShield  
- the conceptual scaffolding for structured provenance in research ecosystems  
- the dignity of continuing research under material constraint  
- the reality that the author is a cognitive geometric researcher, not a software engineer  

This repository is a research artifact, not a production software tool. It reflects the lived conditions of its creation: working on a tablet because a laptop cannot be repaired, navigating transnational repression, and maintaining dignity under constraints while continuing structural AI research.

The provenance generator’s instability is not a failure of concept.  
It is a record of the environment in which the work was done.  
And that, too, is provenance.
