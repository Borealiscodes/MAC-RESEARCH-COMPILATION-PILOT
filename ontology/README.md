Artifact Descriptions

1. Citation Ontology (MACv1.0)
   Defines citation classes (A–E), altitude tags (A0–A5), membrane categories,
   contamination guards, provenance rules, and citation operators.

2. Forest-Layer Harmonization — Constellation Geometry
   Node-edge harmonization model for reversible, contamination-safe traversal
   across altitudes.

3. Forest-Layer Harmonization — Manifold Geometry
   Atlas-based harmonization model for reversible, membrane-preserving chart
   transitions across altitude patches.

4. Ontology Index
   Navigation spine listing all ontology artifacts and their relationships.

5. Ontology Changelog
   Version history, provenance metadata, and structural updates for all ontology
   artifacts.

6. Explainers
   Accessibility-layer explainers (A2.5) providing intuitive descriptions of
   ontology artifacts.
